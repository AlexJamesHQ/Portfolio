## ✨ About

This project is my personal portfolio website, designed to present my work, skills, and projects in a clean and modern interface.

The portfolio highlights my experience in UI/UX, web development, app development, 3D design, branding, and open-source projects. It is fully responsive, lightweight, and optimized for desktop and mobile devices.
