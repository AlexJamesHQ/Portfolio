# Alex James — 普通のコーダーとゲーマーの男の子です

> **Ordinary coder & gamer boy.** A personal portfolio and creative engineering showcase built with **React 19**, **TypeScript**, **Tailwind CSS v4**, **GSAP**, **Motion**, **Matter.js**, and **OGL (WebGL)**.

Designed for fluid interactions, typography animations, and real-time physics.

---
---

## ✨ Key Features

- **SplitText Typography (GSAP & ScrollTrigger):**
  - Character-by-character and word-by-word reveal animations with interactive physics-based lift hover effects.
  - Powered by `@gsap/react`, `gsap/ScrollTrigger`, and `gsap/SplitText`.

- **Real-Time WebGL Shaders (OGL):**
  - **Shader Flow:** Silky, organic fluid waves running on custom GLSL fragment shaders.
  - **Portrait Morph:** Interactive fluid ripple morph between portrait states on cursor hover.

- **Matter.js 2D Physics Engine:**
  - Interactive falling chips in the Tech Stack section with gravity, drag constraints, and restitution physics.

- **Polaroid 3D Tilt Strip:**
  - Spring-damped magnetic mouse/touch tracking for realistic photo tilt effects.

- **Curated Projects Showcase:**
  - Responsive masonry grid highlighting key products, including **LunarTune** (featured YT streaming client).

- **Theme Engine (Dark / Light Mode):**
  - Instant theme switching with smooth native View Transitions and retro corner frames.

- **Content Protection & Touch Callout Prevention:**
  - Built-in anti-copy discipline (`user-select: none`, disabled copy/cut/contextmenu) and touch callout prevention (`-webkit-touch-callout: none`).

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:**
  - [GSAP (GreenSock)](https://gsap.com/) & [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)
  - [Motion (Framer Motion v12)](https://motion.dev/)
  - [Lenis](https://github.com/darkroomengineering/lenis) (Smooth Inertial Scrolling)
- **WebGL / Graphics:** [OGL](https://github.com/oframe/ogl) (Minimal WebGL library)
- **Physics:** [Matter.js](https://brm.io/matter-js/) (2D rigid body physics)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Fonts:** Geist, Geist Mono & Fraunces

## 📦 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm 9.x or higher

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/AlexJamesHQ/portfolio.git
cd portfolio
npm install
```

### Development Server

Run the development server locally:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build for Production

Compile TypeScript and build the optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## ☁️ Deployment

### Deploy to Vercel

1. Push your repository to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/) and click **Add New... > Project**.
3. Import your GitHub repository.
4. Set the Framework Preset to **Vite** (default).
5. The included `vercel.json` ensures all client-side routes (`/`, `/projects`, `/about`) are routed cleanly without 404 errors.
6. Click **Deploy**.
